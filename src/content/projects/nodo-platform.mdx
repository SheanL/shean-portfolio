## What Is NODO?

**NODO** is an inclusive social platform and PWA developed for the *RISE Project (2024–2025)* at HOGENT — built for users with special accessibility needs, supervised by educators. Our team of 6 built a fully working product from scratch in one semester.

### Tech Stack

| Area | Technology |
| :--- | :--- |
| Framework | .NET 9, C# 13, Blazor WebAssembly |
| Real-Time | SignalR WebSockets |
| Database | Entity Framework Core 9 + MongoDB |
| Cloud | Google Cloud Platform (GCP) |
| Testing | 82.88% automated coverage |
| Maps | OpenStreetMap geocoding |

### Key Features

- 💬 **Real-time chat** with SignalR WebSockets (text + voice notes)
- 🆘 **SOS Emergency Button** — one tap to reach an educator
- 🤖 **AI Chatbot** — auto-escalates to a human after 10 messages
- 🚫 **Auto-Censorship** — profanity masked in real-time, educator alerted
- 📴 **Offline PWA** — messages queue in IndexedDB and sync on reconnect
- 🏢 **Multi-tenant Admin** — facility and user provisioning (shared team responsibility)
- 🧩 **Accessible Games** — Memory, Cards, Quiz, Blocks with multi-player

## Wat Is NODO?

**NODO** is een inclusief sociaal platform en PWA ontwikkeld voor het *RISE Project (2024–2025)* aan HOGENT — gebouwd voor gebruikers met toegankelijkheidsbehoeften, begeleid door educators. Ons team van 6 bouwde een volledig werkend product van nul in één semester.

### Tech Stack

| Gebied | Technologie |
| :--- | :--- |
| Framework | .NET 9, C# 13, Blazor WebAssembly |
| Real-Time | SignalR WebSockets |
| Database | Entity Framework Core 9 + MongoDB |
| Cloud | Google Cloud Platform (GCP) |
| Testen | 82,88% geautomatiseerde testdekking |
| Kaarten | OpenStreetMap geocoding |

### Kernfunctionaliteiten

- 💬 **Real-time chat** via SignalR WebSockets (tekst + spraakberichten)
- 🆘 **SOS Noodknop** — één tik om een begeleider te bereiken
- 🤖 **AI Chatbot** — escaleert automatisch naar een mens na 10 berichten
- 🚫 **Automatische Censuur** — scheldwoorden direct gemaskeerd, begeleider gewaarschuwd
- 📴 **Offline PWA** — berichten gebufferd in IndexedDB, sync bij herstel
- 🏢 **Multi-tenant Beheer** — faciliteiten en gebruikersprovisioning (gedeelde teamverantwoordelijkheid)
- 🧩 **Toegankelijke Spelletjes** — Memory, Kaarten, Quiz, Blocks met multiplayer
