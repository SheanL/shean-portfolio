## 1. Introduction & Overview

**B2B Commerce Platform** is a full-stack enterprise Business-to-Business solution developed for the *Software Development Project II (SDP II)* course at HOGENT (2024). The platform connects suppliers, business clients and administrators in a multi-tier B2B ecosystem.

The system encompasses three core components:
1. **Frontend Web Portal**: React 18, TypeScript, Tailwind CSS and Vite.
2. **Backend REST API**: Node.js, Express, Prisma ORM, JWT Authentication and MySQL 8 database.
3. **Java Desktop Client**: Java 21, JavaFX and REST client integration for internal administrative management.

---

## 2. Technical Architecture & Tech Stack

### Frontend Architecture
* **React 18 & TypeScript**: Strongly typed component architecture with custom hooks.
* **Tailwind CSS & Lucide Icons**: Responsive, accessible dark/light UI design.
* **State Management & Routing**: React Router v6 and Axios HTTP client with automated JWT interceptors.

### Backend & Database Architecture
* **Node.js & Express**: High-concurrency RESTful API endpoints.
* **Prisma ORM & MySQL 8**: Type-safe relational database queries, schema migrations and relational data modeling.
* **Security & Auth**: Role-Based Access Control (RBAC), bcrypt password hashing and JWT bearer tokens.

### Java Management Client
* **Java 21 & JavaFX**: Desktop management software for internal administrators to manage orders, suppliers and catalog inventory.
